## 🚀 Featured Projects

**[Wealthy](https://github.com/amanjot1800)** is a portfolio intelligence platform.
`TypeScript` `React` `Python` `SQLite` `Claude API`
It's a stateful portfolio analytics web app with a React/TypeScript front end that renders live portfolio data. Scheduled Python pipelines ingest real-time market data and generate daily profit/loss summaries. AI-driven features use the Claude API to turn price history, company fundamentals, and technical indicators into insights.

**[HintonMarket](https://github.com/amanjot1800)** is a farmers market management system.
`C++` `Qt` `SQLite`
It's a desktop retail app with inventory, sales, customer, and reporting modules. It uses object-oriented design on a relational SQLite backend, and its Qt interface is integrated with the backend components.
